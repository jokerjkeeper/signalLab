# AI 風投項目掃描 — Prompt 範本與來源清單

給「**能上網搜尋的 AI**」(Perplexity / Claude.ai 開搜尋 / ChatGPT 搜尋等)用的提問範本,
用來偶爾掃描「最近風投圈有什麼特別的 AI 項目」,並挑進 Signal Lab 追蹤。

> ⚠️ 純語言模型(沒連網)會給過時或編造的答案,**時效性需求一定要用有搜尋能力的工具**。
> 在 Claude Code 裡可直接用 `/signal-scan` 由 Claude 幫你跑搜尋並輸出匯入格式。

---

## 1. 通用範本(複製即用)

```
請用網路搜尋,列出「最近兩週」內公開募資、或剛發表、比較特別的 AI 新創。

條件:
- 時間:近 14 天(請以實際發布日為準,標註日期)
- 數量:8~12 個
- 「特別」的定義:有獨特切入點 / 非單純 ChatGPT 套殼 / 有明確護城河或客戶
- 每個項目請給:
  1) 名稱
  2) 一句話在做什麼
  3) 募資金額與輪次(若有)
  4) 為什麼值得注意(1~2 句)
  5) 官方網址 + 我能查證的新聞來源連結

重要:
- 一定要附上可點擊的來源連結
- 查不到確切日期或金額就標「未知」,不要猜
- 不確定真實性的項目,直接說明,不要編造
```

## 2. 主題變體

**② 教育類**
```
（同通用範本,但聚焦）
「AI 教育 / 學習 / 培訓」領域的新創,特別是印證
「AI 讓課程生產成本趨近於零」這個趨勢的項目。
```

**⑤ 決策整合 / 法律 / 醫療**
```
（同通用範本,聚焦）
「AI 把過去案例數據 + 當下決策需求整合輸出」的項目,
例如法律(判例/合約)、醫療(病歷/診斷)、金融(風控)領域。
```

## 3. 進階版:輸出可直接貼回 Signal Lab

```
請用網路搜尋找近兩週特別的 AI 新創,每個項目用以下格式輸出(方便我匯入追蹤工具):

名稱 | 來源平台 | 類別(教育/決策整合/基礎設施/數據/醫療/工具) | 官網 | 募資 | 描述(2句) | 為何值得追(1句) | 來源連結

至少 8 個。查不到的欄位填「未知」,不要編造。
```

> 欄位對應 Signal Lab 的 `Project`:類別→`category`、描述→`desc`、為何值得追→`notes`。

## 4. 推薦來源清單

### 📧 電子報(讓別人先幫你篩好,最省力)
- **Axios Pro Rata**(Dan Primack)— 每日創投募資,最快
- **StrictlyVC** — 創投圈日報
- **Ben's Bites** / **The Rundown AI** — AI 專門,含新產品與募資
- **TLDR AI** — 每日 AI 摘要,精簡
- **Crunchbase News** — 募資數據導向
- **Newcomer**(Eric Newcomer)、**The Information** — 深度,部分付費

### 🟠 YC
- `ycombinator.com/launches` — Launch YC,新公司首發
- `ycombinator.com/companies` — 可依 batch / 產業(Education、Healthcare…)篩
- YC **Requests for Startups** — 看 YC 自己想投什麼方向

### 🟣 Product Hunt
- `producthunt.com` → 看 **AI 分類** 與每日 / 每週榜
- 適合看「已上線、有人用」的產品(比募資新聞更早能試用)

### 🐦 X(Twitter)
- 與其追單一帳號,建議**自建一個 List**,丟進三類:創投記者、AI 電子報主理人、funding 速報帳號
- 高辨識度起手:`@bensbites`、`@TheRundownAI`、`@Crunchbase`、`@ericnewcomer`
- ⚠️ 帳號會改名/搬家,加之前先點進去確認本人

---

## 5. 使用提醒

1. **一定要點來源連結查證** — 會搜尋的 AI 偶爾抓到舊聞或金額誤植
2. **時效** — 「近兩週」不同工具理解的「今天」可能不同,以它標的**實際日期**為準
3. **發現 vs 分析** — 這些範本是「發現」;找到後挑進 Signal Lab,單一項目的深度分析是另一回事
